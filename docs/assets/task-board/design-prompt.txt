Use case: ui-mockup.
Create ONE realistic, production-quality desktop UI design for Ait, named “任务总览”. Redesign the attached Better Paseo board into the agreed Ait feature. This is a high-fidelity, implementable application screen with Chinese interface text, NOT a poster, not a landing page, and not a collection of alternatives.

Input images:
1. Better Paseo Tasks board screenshot: structural reference for a real multi-agent status board, compact task cards, left application sidebar, and right details panel. Simplify the clutter of pills and toolbar controls.
2. Existing Ait welcome screen: source of Ait's orange origami bird branding, clean light theme, system typography and restrained green primary action. Do NOT recreate the welcome-screen layout.
3. X Fleet screenshot: visual reference for subtle parent-child connections only inside the right task details panel. Do NOT put a large fleet graph in the main board.

Target dimensions: 1920 × 1080 desktop application viewport, landscape 16:9. Flat front-on screenshot, edge-to-edge app, no device bezel, no browser chrome, no perspective, no surrounding presentation canvas. Make all small Chinese text crisp and readable. Natural typography, no stretched elements.
Current date anchor: 2026-11-10 in Asia/Singapore. Only use relative times such as “等待 3 分钟”, “运行 12 分钟”; do not show invented calendar dates.

Product goal: a developer managing coding agents on multiple computers can immediately see which tasks need intervention, which are running, and which replies need review; selecting one task opens useful details and a permission decision.

Use system sans-serif / PingFang SC for Chinese, 14–16 px body at the intended viewport, 24 px screen heading, 12–13 px metadata. Lucide-style 1.5 px line icons consistent with existing Ait. Card radius 8 px, control radius 6 px. Purposeful 8/16/24 px spacing. No gradients, no glossy glass, no oversized metrics. Use grouping and spacing first, light dividers second, almost no shadows. Status color is a small dot or small badge rather than a saturated large surface.
