# 客户端登录：自动续期待办

更新：2026-11-03。Desktop、Android、iOS 可保存用户会话，Web 可恢复持久凭据；关闭应用不应清除登录。
当前共享客户端按中心返回的 `expires_in` 保存到期时间，没有用户会话 refresh token，过期仍需登录。
实际行为见[统一登录](../operations/authing-client-login.md)，旧期限调整与验证见
[2026-10-10 记录](../archive/plans/relay-client-session-persistence.md)。

## 待实施的协议

以下是设计工作，尚未接入，不能用机器授权刷新接口替代用户会话续期。

- [ ] 中心为客户端创建可独立撤销的会话，返回短期访问令牌和可轮换续期凭据；定义期限、轮换、幂等恢复与撤销语义。
- [ ] 统一账号有效期、身份提供商授权期限、访问令牌和客户端节点租约的校验，避免令牌已续期而节点仍按旧期限失效。
- [ ] 共享客户端合并启动、回前台和临近到期的刷新；可靠保存轮换结果，网络故障保留凭据并重试，明确失效后才重新登录。
- [ ] 保持用户会话与 daemon 机器授权独立：客户端退出清除用户凭据，显式主机断开才撤销 daemon 授权，见
      [ADR-201](../decisions/daemon/adr-201-daemon-owned-publication.md)。
- [ ] 先部署兼容旧客户端的中心，再发布客户端；旧会话无续期凭据，需重新登录建立新会话。

验收覆盖隔夜重开、断网、并发刷新、轮换落盘中断、多设备、主动退出、账号到期和撤销。
Android/iOS 安全存储及 Desktop 密钥环应在安装包上验证。原方案的 15 分钟/30 天是示例值，不能作为已确定的服务期限。
