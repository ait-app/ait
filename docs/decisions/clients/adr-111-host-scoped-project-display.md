# ADR-111：项目显示身份按主机隔离

- 状态：已实现
- 日期：2026-10-09
- 关系：沿用 [ADR-025](../workspace/adr-025-paseo-registry.md) 的主机内 Project/Workspace 登记身份，修订客户端将相同仓库跨主机归组的显示行为。

## 背景

本地和远程机器都检出 `ait` 时，客户端使用 Git remote 派生的 `projectKey` 作为显示分组身份。
即使两边 Project 和 Workspace 的 ID 不同，相同仓库的条目仍出现在同一个 `ait` 分组下。
分组的新增工作区、设置、图标和删除入口也会受到多主机归组的影响。

## 决策

- 共享客户端的项目结构统一以 `(serverId, projectId)` 的 JSON 元组作为 `viewKey`。相同名称、Git remote、路径或主机内 ID 都不能跨主机合并显示。
- 每个显示项目只包含该主机、该 Project 的 Workspace；同一主机上的多个检出继续独立显示。
- `projectKey` 保留为仓库等价信息。切换创建工作区的目标主机时，等价候选和精确候选必须实际存在于选中的主机上。
- Workspace 条目和会话继续使用主机内身份及已有主机隔离的数据、路由和标签页状态。本次不修改 daemon registry、协议或 Provider 会话记录。

## 后果

两台机器的 `ait` 显示为两个独立分组，各自操作自己的主机与条目。
显示身份不再随 Git remote 的添加、删除或修改而变化。

旧的跨主机分组排序、折叠偏好和图标缓存使用旧 `viewKey`，新分组采用默认显示偏好；
Workspace 和会话标签页的持久化键不变，无需迁移会话数据。

回归验证覆盖同仓库跨主机隔离、相同主机内 ID、remote 变更时的稳定身份、同主机多个检出、
项目摘要、侧边栏订阅和创建工作区时的目标主机选择。
