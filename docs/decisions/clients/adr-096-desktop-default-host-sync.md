# ADR-096：Desktop 内置 daemon 默认同步与手动下线

- 状态：已实现
- 日期：2026-10-07
- 关系：修订 [ADR-083](adr-083-online-service-host-sync.md) 的桌面默认发布行为，沿用 [ADR-085](adr-085-stable-daemon-publication.md) 的稳定主机身份。

## 背景

Desktop 用户登录在线服务后仍需进入内置 daemon 的连接设置才能让本机上线。
默认上线应与登录衔接，同时必须尊重用户之后主动停止同步的选择。
添加主机的在线服务面板使用嵌套背景卡片，与直接连接的表单布局不一致。

## 决策

- Desktop 账户节点注册成功后，共享界面的同步生命周期默认启用内置 daemon 的独立主机租约。仅匹配桌面运行时提供的 server ID；TCP、SSH 和移动端主机继续由用户手动启用。
- daemon 必须处于运行状态，已建立鉴权连接并声明在线服务同步能力。登录和应用恢复时立即检查；启动较晚、daemon 重启或同步失败时沿用后台检查与重试。
- 主机注册继续使用 daemon 的稳定 server ID，并使用既有逐主机账户授权和一次性控制票据；客户端节点不绑定运行时，用户账户令牌仍由 Electron 主进程持有。
- 主进程在 `account-node.json` 中保存非秘密偏好 `syncBuiltInDaemon`，旧配置缺失该字段时默认启用。手动停止内置 daemon 同步时关闭该偏好；退出登录、重新登录、应用退出或重启都保留该选择。用户主动重新启用本机同步时恢复默认上线；其他主机的同步操作不改变该偏好。
- 在线服务添加主机界面沿用直接连接页的独立字段标签、自适应输入控件、间距、背景和底部主操作。服务地址折叠显示，在线主机使用图标、状态和选中标记；选择后的 sheet 关闭与导航顺序保持既有行为。

## 后果

Desktop 默认注册本机，但手动下线具有持久优先级。账户、租约和 daemon 控制连接的归属不变；不增加 Rust 接口、中心协议或 daemon 持久账户凭据。

验证覆盖桌面偏好存储、登录与启动生命周期、身份与重试、移动端边界和登录交互。
