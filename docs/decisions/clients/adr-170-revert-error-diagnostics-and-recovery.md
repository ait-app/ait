# ADR-170：完整回滚 PR #381

- 状态：Accepted
- 日期：2026-10-20
- 取代：ADR-161、ADR-162；ADR-166 随其依赖的诊断链路撤销。

## 决策

0.1.9 的 iOS 客户端出现停留在启动画面的问题。用户明确要求完整回滚
[PR #381](https://github.com/ait-app/ait/pull/381)。
反向应用其合并提交 `4347b217f2e4b29a2f466bc5e7ce4906c19875dc`，恢复此前的客户端错误提示、
SDK 诊断日志、Codex 失败分类和会话启动行为。移除应用入口的全局错误采集、统一诊断复制／导出、
Codex 原生错误详情展示，以及 daemon 重启后自动收尾中断轮次的逻辑。

保留后续 PR 引入的独立功能。ADR-166 依赖被移除的诊断采集器，其后台错误记录策略同时失去
执行入口；文档保留为历史记录。没有数据库迁移，也不修改已发布的安装包；移动端修复仍需重新构建分发。

## Test coverage

**not measured**：用户未请求覆盖率；验证限定受影响的 Provider、客户端和 SDK 行为。
后续若需测量，使用 `cargo llvm-cov` 限定相关 Provider 测试，客户端限定回滚涉及的 Vitest 文件。
