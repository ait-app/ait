# ADR-124：登录后自动添加全部在线服务主机

- 状态：已实现
- 日期：2026-10-11
- 关系：修订 [ADR-083](adr-083-online-service-host-sync.md) 的主机选择交互，以及 [ADR-122](adr-122-persistent-online-service-hosts.md) 的显式添加策略；沿用 [ADR-123](adr-123-browser-only-account-login.md) 的统一浏览器登录。

## 背景

在线服务登录后仍需要在账户面板单独选择一台主机。账户发现列表与公共主机列表分离，多台在线主机无法直接出现在「添加主机」所在的公共列表中。

## 决策

- 账户面板移除在线主机选择与单台断开按钮，保留统一浏览器登录、账户状态、服务地址、刷新和退出登录。添加主机与欢迎页的登录弹窗在登录成功后关闭；欢迎页等待关闭完成及主机就绪，再进入公共项目入口。
- Desktop、Android 和 iOS 的在线账户快照仅将已确认在线、具备 server ID、instance ID 和兼容中继模式的主机加入既有持久注册表，以 daemon 的 server ID 合并直接连接与服务连接，保留用户名称、外观和连接偏好。
- 同一发现批次统一写入存储，写入成功后才更新运行时列表。发现任务顺序执行；存储失败允许后续重试。重复快照不重复写入、通知或重建连接。
- 每次登录记录用户主动删除的服务连接身份。用户在本次登录中删除的主机或中继连接不会被重复刷新重新添加。退出登录清除删除记录，下次登录可重新导入全部发现主机。发现写入期间若主机注册表改变，基于最新记录重新合并。
- 延续既有持久主机语义：离线、退出登录和服务切换保留主机记录；仅匹配当前已登录服务且已确认可路由的中继连接可以激活。离线的纯中继主机从日常主机选择器和首页错误汇总中过滤，设置仍可管理已保存记录；带直接连接的主机不受中继离线状态影响。状态通道重连期间保留健康的数据连接，明确离线后停止中继探测，重新上线后自动恢复。账户代次变化或界面卸载后，等待中的旧发现任务不更新运行时。
- 沿用平台管理器对独立主机访问和下载的授权，服务地址保存在连接记录中，凭据和一次性票据仍归平台管理器。不修改中心协议或 Rust daemon。

## 后果与验证

用户登录一次后即可从公共主机列表使用所有在线服务主机，重启后仍可恢复已保存主机。每台主机通过自己的连接独立访问，账户页不再承担主机选择。

定向回归覆盖全部主机导入、与直接连接合并、持久保存、重复刷新、删除后的刷新、新登录重新导入、存储失败与并发发现、独立连接，以及登录弹窗关闭与导航。
