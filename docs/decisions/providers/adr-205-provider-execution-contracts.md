# ADR-205：Provider 执行归属与公共端口契约

- 状态：Accepted
- 日期：2026-10-31
- 延续：[ADR-179](adr-179-provider-owned-tests.md) 的 Provider 自有行为测试。

执行器原先通过方法字符串和 `agentId` 字段推断请求归属，漏掉了以
`parentAgentId` 寻址的原生子会话。独立读取分支没有实时会话，可能用滞后的原生历史
覆盖已提交的子会话内容，也无法还原会话动态发现的功能和模式。

保留现有 JSON wire 方法、参数和响应，在执行器准入时把方法转换成封闭的
`Operation` 枚举。工作队列、调度和顶层分派使用枚举；每个操作必须明确访问类别和
目标身份的位置，新增操作不能靠名称前缀自动获得读权限。JSON 参数继续在所属 RPC
适配器中按协议类型校验，原生 Provider 的扩展字段保持不透明。

子会话列表和历史读取归父 Agent 的会话所有者。实时子会话已有投影时直接读取已提交
条目，不等待或重放可能滞后的原生文件；缺少投影或不再实时拥有子会话时，仍走验证过
父子关系的原生历史路径。不支持的回退必须先拒绝，再考虑停止回合、关闭写入端或撤销输入。

独立 get/list 读取复用所有者最近发布的动态模式与功能，但仅限 Agent、Provider、
原生持久身份、配置和 runtime 信息都相同。比较所需的配置只保存在内存中，不加入响应
或事件；事实变化或没有匹配快照时使用当前持久信息和静态设置。这样保留读取的独立性，
同时不让旧快照掩盖新配置。

预设 `AgentCatalog` 保持可由外部 crate 实现的端口：服务负责验证并生成命令，适配器
通过只读访问器消费命令，通过公开构造器返回回执；调用方可直接使用类型化的 `Agents`
服务。命令字段仍不公开可写。独立集成测试只使用公共 API 实现内存适配器，验证此边界
可用；执行行为回归测试留在 `crates/provider` 的执行服务旁。
