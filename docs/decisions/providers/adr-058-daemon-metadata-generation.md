# ADR-058：Server 的有界 metadata generation

- 状态：Accepted
- 日期：2026-09-27
- 关联：ADR-001 v4、ADR-031、ADR-032、ADR-050、ADR-052

生成接口归属及配置注入现由 [ADR-100](adr-100-provider-summary-generator.md) 修订；原有配置键和生成行为保留。

## 背景

独立 Rust Server 已保存 `metadataGeneration.providers` 和 `paseo.json` 的文案配置，
但没有消费者。首条输入只能形成临时 session 标题；工作区的占位分支、空提交信息和
缺省 PR 文案也没有生成链路。本次比照固定版本 Paseo
`2c8e8a826810337492cc5a38bb0bbd705b6fb632` 的四类 metadata 功能实现。

## 决策

1. `metadata` 定义异步 `MetadataGenerator` 出站端口，输入仅含种类、cwd、
   有界源材料和当前 Provider/model/reasoning 选择。`provider` 实现配置解析、
   候选回退、JSON 校验及原生生命周期，host 注入同一实例。metadata 不依赖 provider。
   `WorkspaceBranchNamer` 是 metadata 的独立阻塞 Git 端口，由 filesystem 实现。
2. 优先使用实时配置中的有序候选，再尝试已发现的小模型，最后尝试当前 session 选择；
   排除禁用 Provider，去重模型/推理组合。显式模型不要求先发现成功；省略模型时使用
   Provider 默认。自动偏好对齐 Paseo 的 haiku、gpt-5.4-mini（支持时 low）、minimax-m3、
   nemotron-3-super；当前 Server 实际可运行的原生适配器仍是 Codex 和 Claude。
3. 全局最多 32 个已接纳的生成操作、2 个并发原生请求；总期限 90 秒，单次原生调用
   25 秒，发现每个 Provider 最多 5 秒。无效 JSON 最多修复两次，传输错误直接换候选。
   源材料和输出均有长度预算。项目根 `paseo.json` 中非空 instructions 替换各自默认
   风格，固定 JSON/只读约束不被替换。解析失败时使用默认风格。
4. Codex 使用 `ephemeral` thread、只读 sandbox、never approval、JSON outputSchema，
   关闭 shell、多 Agent、apps/plugins、hooks、goals、memories、notify、web search、MCP
   和项目指令文件加载。Claude 使用
   no-session-persistence、空工具集、严格空 MCP、禁用 hooks 和 JSON schema。
   辅助调用不注册公开 Agent、不追加 Timeline、不改变前台 Run；完成、超时、取消均
   关闭原生进程。配置和日志不复制认证凭据。
5. session 的持久快照新增可选 `titleOrigin`（prompt/generated）。只有临时标题可以
   被后台结果替换；手工改名清除此标记，即使改成相同文本也能阻止迟到结果。
   原生显式标题、旧有非空标题及 internal Agent 不覆盖。启动保留本地文本回退，并在
   后台处理具有临时来源标记的记录；失败保留临时标题，不影响前台输入。
6. Workspace 新增可选 `autoName`，记录待生成资格和系统占位分支。目录创建、worktree
   创建的 firstAgentContext，以及先创建工作区后到达的首条 Agent 输入都能触发生成。
   原子更新重新检查身份、目录、标题、归档状态和资格，只写自己的标题/分支字段。
   手工标题编辑清除资格。只有 managed worktree 的当前分支仍等于系统占位名且没有
   upstream 时才自动改名；用户指定或后来切换的分支保留。命名碰撞最多尝试 50 个后缀。
7. 空提交信息从 uncommitted diff 生成；PR 缺 title/body 时从指定 baseRef 的提交差异
   生成，仅填缺省字段。读取 Git 失败仍报错，模型失败分别回退到 `Update files`、
   `Update changes` 和 `Automated PR generated by Ait.`。生成期间不占用全局文件系统
   job permit，不把模型等待放进 Git 服务锁内。
8. Server drain 首先取消共享生成器和工作区命名任务，再等待已有任务；Provider worker
   清理其标题任务。已启动的阻塞 Workspace 更新仍在独立 tracker 中，避免重启时旧任务
   越过实例租约写回。

## 边界与兼容

新增持久字段可缺省，旧记录不被猜测为可覆盖的自动标题。字段不加入现有 wire descriptor，
已有客户端无需改协议。domain 只新增纯数据枚举，没有 Tokio/HTTP/Provider 依赖。
Message 不可变性、Session 指针和 Run 终止规则不变；生成结果是展示元数据。

Paseo 这四类配置没有独立的 session 摘要接口，本次也不扩展一套摘要协议；旧应用领域模型
中的 description 不被当成独立 Server 的已有能力。与 Paseo 相比，队列、期限、进程隔离和
手工同值改名保护更明确。验证、测量范围与剩余限制见[报告](../../reports/providers/metadata-generation.md)。
