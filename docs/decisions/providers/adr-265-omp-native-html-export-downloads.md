# ADR-265：OMP 原生 HTML 导出与一次性下载

## 背景

已保存 Timeline 的通用导出由 Ait 渲染，不包含 OMP 的原生日志和查看器。OMP 原生 HTML
包含完整原生日志，可能执行脚本并从远程加载查看器，因此不能当作通用导出的惰性 HTML。

## 决策

- 对有活动原生会话的 OMP Agent 提供单独的原生 HTML 导出；通用 Timeline 导出不变。
  原生内容原样下载，界面说明活动内容和远程查看器可读取会话的风险，不在 Ait 中预览。
- 使用已有原生会话的单一写者，以关联的异步请求生成文件；导出不得启动第二个会话、
  发送输入或中断活动轮次。其他 Provider 默认不支持此能力。
- Adapter 拥有 OMP 数据目录内的私有暂存位置，确认产物是受限大小的自有常规文件后，
  复制原始字节至匿名文件。暂存路径和原生日志不进入公共协议。取消、超时或连接关闭时
  处理晚到响应和文件清理，不删除其他请求的文件。
- 文件复制由有界后台工作执行，取消不会提前删除仍在使用的目录；无法确认原生进程已退出
  时保留暂存目录直至观察到退出。若一直无法确认退出，目录可能残留；暂存创建与清理的
  元数据操作仍受底层文件系统响应时间影响。
- 类型化 `agent.native_html.export.request` 与取消方法复用既有 artifact 交接及 Files
  一次性下载授权。客户端只有在两个方法均协商成功时才启用入口；旧 Host 不会收到新请求。
  下载完成、取消和授权到期遵循现有下载语义，不自动重新执行原生导出。
- 生成请求使用客户端提供的 UUID v4 操作 ID；取消请求以该 ID 取消正在生成的任务，或以
  已签发的 token 释放产物，两个参数互斥。生成和取消绑定同一连接与 Agent，重复或先到的
  取消保留 60 秒记录，每个连接最多 128 条活动或未过期记录；连接断开时放弃该连接的在途任务。
- 原生日志可能比共享 Agent 的 Timeline 投影包含更多信息，因此访客不能请求或取消原生
  导出；已有的共享 Timeline 导出权限保持不变。

## 后果

原生导出保留 OMP 格式及其安全特性，不能替代 Ait 的通用时间线导出。Adapter、运行时、
API、协议和客户端需要共同维护请求关联、文件所有权和取消语义。
