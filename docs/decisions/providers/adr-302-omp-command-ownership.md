# ADR-302：OMP 命令归属由活动会话裁决

## 背景

内置命令与扩展、技能可能共享名称或别名。仅按文字屏蔽会误拦扩展，而发现进程读取的目录
不一定等于活动会话实际加载的目录。客户端的清空和退出快捷命令还会修改会话状态。

## 决策

- adapter 保留原生目录中的来源与全部名称声明，将菜单展示与命令归属分开。只有确定由内置
  命令独占且由 Ait 接管的入口交给 Ait；扩展独占时交给原生会话；来源不明且可能冲突时拒绝。
- 活动会话由自己的原生目录决定路由，动态目录更新使客户端缓存失效。发现进程只服务尚未创建
  的草稿，不能证明活动会话的归属。会话重启、目录未就绪或排队期间归属改变时，不沿用旧判定。
- 客户端执行清空、退出等快捷操作前重新查询当前目录；旧宿主和不支持归属判断的 Provider
  保持原有兼容行为。无法判断时保留输入并提示用户，而不猜测命令所有者。

## 后果

原生接口没有将目录版本与执行绑定的原子操作；即使在写入前检查，原生扩展仍可能在最后检查后
发生变化。应用只能缩小并公开这个窗口，不能宣称彻底消除。完成列表发现不等于支持原生参数补全；
未通告的能力不发送探测执行请求。
