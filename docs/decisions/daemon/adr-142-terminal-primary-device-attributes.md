# ADR-142：PTY 拥有基础终端设备属性回复

状态：已接受

日期：2026-10-12

## 背景

fish 4 在交互启动时发送 Primary Device Attributes（DA1）查询，并等待回复。
客户端此前抑制此回复，Rust PTY 也未回复，导致 fish 等待 10 秒后报告兼容性警告。
即使客户端放行查询，shell 也可能在首次订阅之前发送它；屏幕快照不会保留这类查询。

## 决策

- terminal crate 使用已有 vt100 解析器识别实时输出中的 `CSI c` 和 `CSI 0 c`，
  通过现有有界 PTY 输入队列回复 `CSI ? 1 ; 0 c`，仅声明基础 VT100，不声明可选能力。
- 回复不依赖客户端连接或订阅，跨 PTY 读取的查询仍由解析器完整识别。
  回复在屏幕锁释放后入队；输入队列已满或关闭时记录警告，继续排空输出，避免双向 I/O 死锁。
- 显示端继续抑制 DA1 回复，避免多个观察者重复回复。快照恢复、尺寸变更和重新订阅
  不重新生成查询回复。DA2、DA3、DSR 和 DECRQM 的行为不在本次修改范围内。
- 本决策补充 ADR-117。颜色及显示相关查询仍按
  [ADR-117](../clients/adr-117-terminal-palette-and-appearance-lifetime.md) 由显示端处理。
  不增加网络消息或 crate 依赖。

## 后果

fish 的基础能力握手在本机完成，首次打开终端不再因缺少 DA1 回复等待客户端或 relay。
能力声明采用保守值，不宣称某个观察者的图像或其他可选能力适用于所有客户端。
升级节点 daemon 即可提供回复，既有客户端的查询抑制与此兼容。

回归测试覆盖分片、连续和非目标查询、订阅前真实 PTY 握手，以及队列满或关闭时的输出排空。
另提供需要本机安装 fish 4 的显式兼容性测试，验证无观察者时 3 秒内出现交互提示符。
